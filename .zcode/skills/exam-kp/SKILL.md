# exam-kp：经济法知识点写作技能

为「军队文职·助理审计·经济法」备考应用生产知识点数据。**写任何知识点前，先读项目根目录 `CLAUDE.md`**（schema 在 §4，法条版本基准在 §5，工作流在 §6），本技能是其操作化说明。

## 硬性红线（违反即返工）

1. **条号零差错**：写入 `original` 的每个条号必须核对。不确定 → 只写法律名+规则内容，**绝不编造条号**。审核清单见 `data/raw/大纲提取_经济学专业科目.txt` 与官方 PDF。
2. **只依据现行法**：以 CLAUDE.md §5 版本基准为准（民法典 2021 施行版等）。已废止的《合同法》《物权法》《担保法》只允许出现在 `background` 的沿革叙述里，且必须注明"已废止/已并入民法典"。
3. **大纲对齐**：`chapter`/`section` 字段必须逐字取自官方大纲（《经济学》大纲第三篇经济法，共 6 章）。考点覆盖以大纲细目为准，不超纲、不漏纲。
4. **id 不重排**：新增用未占用号；已发布 id 永不改动（进度记录与 related 都锚定它）。
5. **排版规范**（Markdown 渲染约束）：正文引号一律中文引号 " " ' '，不用 ASCII 引号；每段一行（段间空行），段内不手动折行；中文字符间不留空格；YAML 标量值不以 ASCII 引号开头。写完跑 `python tools/normalize_points.py` 兜底。

## 写作流程

1. 确认知识点在官方大纲中的位置（章/节/考点细目），从 `data/raw/` 核对表述
2. 按 CLAUDE.md §4 v2 schema 写 YAML，文件放对应章节目录，命名 `<id>_<标题>.yaml`
3. 六件套质量标准：
   - `original`：法条原文逐字准确，注明法律名+中文数字条号（应用中默认折叠，供回头核对）
   - `why_written`：**分点列表**（3~6 点，每点 `- **加粗小标题**：一两句话`），讲"规则为什么这样设计"，末点写跨章联动（纯文字，不写 id）
   - `name_origin`：术语得名缘由——拆词/构词/字面即规则，80~150 字；不写立法沿革
   - `examples`：1~3 个生活案例（买房/网购/开店/借钱/上班等场景），story 讲人话，analysis 点明对应法条规则
   - `exam_tips`：必背数字（期间、比例、人数）、易混淆对比、命题角度
   - `quiz`：1~2 道场景化单选题（question/options/answer/explain），考查核心规则与易错点，答案字母 A/B/C/D 均衡分布
4. `related` 填同章或跨章强关联的既有 id（内部关联用）；引用不存在的 id 是错误
5. 运行校验：`python tools/normalize_points.py` → `python tools/verify_points.py`（必须 0 error）→ `python tools/build_outline.py` 重新生成大纲
6. 抽查自己写的 `original` 中每个条号（对照 §5 基准法条），在 CLAUDE.md 迭代日志追加记录

## 审核他人写的知识点

用 `python tools/verify_points.py --list-articles` 导出全部条号清单，逐条核对；重点抽查：数字类规则（期间/比例/人数）、"视为/不得/应当"句式、新旧法条号变化（如民法典对担保法条文的承继变化）。
